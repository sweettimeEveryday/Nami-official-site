# 西園寺ナミ｜OFFICIAL SITE

> 夜の静けさに。とろけるような声で、あなたの心にそっと触れること。
> あなたの居場所になれるまで。

歌と声劇を中心に活動する **西園寺ナミ** のオフィシャルサイトです。

**公開URL** → <https://sweettimeeveryday.github.io/Nami-official-site/>

## このサイトについて

「遠くから眺める存在ではなく、あなたのお耳のすぐ隣にいる存在でありたい」——
サイト全体をその考え方で組み立てています。

説明を先に置くのではなく、まず作品と姿を見てもらう。
そのためにトップは、**画像が奥から手前へ流れてくる帯**から始まります。
流れてくるカードは押すと開き、YouTube や AWA など、その場所へつながります。

配色は「白磁」。白磁の白に墨の文字、朱を一点だけ。
ページ上で色を持つのが朱だけになるよう、ほかの色は徹底して抑えています。
ヒーローと帯だけが暗いのは、ロゴと背景動画が黒地の素材だからです。

### トップのセクション

- **World / これまでの思い出と、これから** — 奥から手前へ画像が流れるコリドー。カードを押すと中央にパネルが開きます。YouTube・TikTok・AWA・BOOTH の4枚と、歌と声劇の動画20枚、飾りの7枚で全31枚

## 技術

**素の HTML + CSS + JavaScript です。** フレームワークもビルド工程もありません。
`index.html` をブラウザで開けばそのまま動きます。GitHub Pages で公開しています。

- 外部依存は Google Fonts（Cinzel / Shippori Mincho / Zen Kaku Gothic New）のみ
- JavaScript は `assets/js/main.js` の1本だけ
- 「動きを減らす」設定（`prefers-reduced-motion`）に対応。動画を読み込まず、コリドーも静止画として止まります

```
.
├── index.html / profile.html / links.html / goods.html / contact.html
└── assets/
    ├── css/style.css     デザイントークンと全スタイル
    ├── js/main.js        ヘッダー・メニュー・コリドー・スクロール領域
    ├── img/              カード画像・ロゴ・favicon・OGP
    │   └── sp/           カード画像のスマホ用（448px）。自動で作られます
    └── video/            ヒーローのロゴモーション、Worldの背景動画
```

## よく触るところ

### コリドーのカードを足す・差し替える

`index.html` の `.stream__item` の行を編集します。**左右のレールは JavaScript が自動で組み直す**ので、枚数は何枚でも構いません。
右のレールが1枚目・3枚目…、左のレールが2枚目・4枚目…と交互に拾うので、
リンク・動画・飾りをまとめて書いても、左右どちらにも散らばります。

```html
<a class="stream__item" href="リンク先" target="_blank" rel="noopener"
   data-img="assets/img/card-12-xxx.jpg"
   data-pos="20"
   data-en="Song" data-title="タイトル" data-cta="ボタンの文字">説明文</a>
```

| 属性 | 意味 |
|---|---|
| `data-img` | カードに使う画像 |
| `data-pos` | 切り取り位置。`20`＝上下の位置、`30 50`＝左右と上下 |
| `data-title` | **これがある行だけ押せます。** 無い行は飾りのカードになります |

カードは **18:25 の縦長**です。元画像がそれと違う比率だと、はみ出した側が切られます。
`data-pos` は「どこを残すか」を決める数字です（0＝上／左寄せ、100＝下／右寄せ）。

### カードを足す・直す — `01_設計\カード管理.html`

**カードまわりの作業はこれ1本で完結します。** リサイズも、名前づけも、位置決めも、
`index.html` の書き換えも、原本のリネームも、全部この画面の中で終わります。

1. `02_素材\card_原本` に元画像を入れる（大きいままで構いません）
2. `01_設計\カード管理.html` をダブルクリック
3. 初回だけ `D:\ナミサイト制作` を選んで「変更を保存」を許可（**2回目からは自動で開きます**）
4. 左の「未実装」に新しい画像が出るので、ファイル名を入れて、赤枠で位置を合わせる
5. リンクを付けるなら「種類」をリンクありにして、タイトル・説明文・URLを入れる
6. **「この1枚を確定」**。確定した画像は下に18:25／4:3／スマホの3種で並びます
7. 全部確定したら**「すべて完了して書き込む」**。書き込む内容の一覧が出るので確認して実行

**やってくれること**

| | |
|---|---|
| リサイズ | 640px（PC用）と 448px（スマホ用）を同時に生成 |
| 名前 | `card-連番-入力した名前.jpg`。連番は自動で続きから |
| index.html | カードの並びだけ書き換え。**他の場所には触れません** |
| 原本 | `src-連番-名前` にリネーム。**消しません** |
| 控え | `01_設計\index_控え_日時.html`（5世代） |
| 答え合わせ | 書き込み後、全カードの画像が実在するか照合して報告 |

同じ `data-pos` が**帯のカード（18:25）**と**押したときのパネル（4:3）**の両方に効くので、
編集中は3つ並べて見えるようにしてあります。片方だけ見て決めると、もう片方で顔が切れます。

**触る範囲を限定しているしくみ**

`index.html` の中で書き換えるのは `<!-- CARDS:START -->` と `<!-- CARDS:END -->` で
挟んだ内側だけです。**このコメントを消さないでください。** 消えていた場合は
`<div class="stream__src">` の対応する閉じタグを数えて探し直し、それも見つからなければ
**何も書き換えずに止まります**。

カードのHTMLは文字列として持ち回らず、構造化データから固定のテンプレートで組み立てています。
値は必ずエスケープされるので、説明文に `<` や `&` を書いても壊れません。

戻したいときは `01_設計` の控えを `index.html` に上書きしてください。

### 配信サービスのロゴを入れる

`assets/img/brand/` に置いた公式アイコンを、カードの丸の中に出しています。

| | 使っているファイル | 出どころ |
|---|---|---|
| YouTube | `youtube.png` | brand.youtube の Icon パック / Digital / 02 Almost Black |
| TikTok | `tiktok.png` | 開発者向け logo-pack / TikTok Logo Pack / Icons / Black Circle |
| AWA | （画像なし。文字で「AWA」） | 公式の配布ファイルが見当たらないため |

画像は**縮小も加工もしていません**。表示の大きさだけ `style.css` の
`.card__ic img`（26px）で決めています。公式アイコンは背景の色面までが1セット
なので、線のアイコンより大きく出さないと中の絵が潰れます。

**ロゴの色と形は変えられません。** 各社のガイドラインで改変が禁じられているため、
サイトの配色に寄せることはできません（大きさの変更だけは認められています）。
TikTokは開発者向けガイドラインに「事前の書面による許諾が必要」と書かれています。

画像が読めなかったときは、もとの英字（YT / TT）に自動で戻ります。
差し替えかたは `assets/img/brand/README.txt` に書いてあります。

### スマホの通信量について

Worldのカード画像はPCで640px、**スマホでは `assets/img/sp/` に置いた448px版**を読みます。
画面幅900px未満で切り替わり、31枚で約5.1MB → 約2.6MBになります。

`sp/` は `01_設計\カード管理.html` が画像を書き出すときに自動で作ります。
**`sp/` が無くても壊れません**——読めなかった画像は元のほうへ自動で戻ります
（ただしスマホで1枚につき1往復むだが出ます）。

### 配色を変える

`assets/css/style.css` の末尾、`配色: 白磁（Porcelain）` のブロックを編集します。
`:root` の変数だけでなく、**そのすぐ下の上書きブロックも一緒に見てください**。
もとのCSSには黒が直接書かれた箇所が8つあり、そこを変数化して上書きしています。

### ヒーローの、動画が終わったあとの1枚

ロゴのアニメーションは1回だけ再生して止まりますが、動画は 2560×1440 しかありません。
ヒーローは画面いっぱいなので、Retinaのノート（実画素 2880×1800〜3024×1964）では
**1.25〜1.36倍に引き伸ばされて**ぼやけます。

そこで、再生が終わったら高解像度の静止画へ **2秒かけて溶け込ませて**います。

| ファイル | 使う場面 | いま入っているもの |
|---|---|---|
| `assets/video/logo_final_3840x2160.jpg` | 横長の画面 | 動画の最終フレームを拡大・補正した暫定版 |
| `assets/video/logo_final_2160x2160.jpg` | 縦長の画面（スマホ） | 同上 |

**この2枚は暫定です。** 元のアニメーションから最終フレームを書き出して、
同じ名前で上書きしてください。**コードを触る必要はありません。**

暫定版には色の調整が入っています（動画の終わりから浮かび上がったとき、
そのままだと沈んで見えるため）。数値は次のとおりです。
書き出したフレームに同じ調整をかけたい場合は、この値を使ってください。

- 銀（無彩色寄りの部分）… 明るさ **1.60倍**
- 赤（彩度の高い赤の部分）… 明るさ **0.92倍**、さらに彩度を **18%** 落とす

赤を上げずに下げているのは、銀が明るくなると赤が相対的に浮いて、
きつい印象になるためです。

書き出しの条件は3つだけです。

- 大きさ … 横長は **3840×2160 以上**、縦長は **2160×2160 以上**
- 中身 … 動画がぴたりと止まる、**いちばん最後のフレーム**。位置がずれると切り替わりが見えます
- 形式 … JPEG（品質85前後）。透過は不要です。背景は動画と同じ黒で

ファイルが無くても壊れません。読めなかったときは、いままでどおり動画の最終フレームで止まります。

### 背景動画を差し替える

`assets/video/` に置き、ファイル名を変えなければコードの変更は不要です。
PC用（`stream_bg_1440.mp4`）とスマホ用（`stream_bg_900.mp4`）を画面幅で出し分けています。
色を変えたときは、帯の端を溶かす `--band-stream` を動画の暗部に合わせて測り直してください。

## 触る前に知っておきたいこと

**遠近法は `.stream` ではなく `.stream__scene` に置いています。**
`.stream` 自身に `perspective` を持たせると、z がマイナスのカード（＝奥のカード）が
背景動画より後ろに描かれて消えます。この入れ子を平らにしないでください。

**`.stream__card` の `!important` は意図的です。**
`style.css` 末尾の `@media (prefers-reduced-motion:reduce){ *{animation:none!important} }` が
コリドーのアニメーションを消してしまい、全カードが中央に潰れます。
そのため打ち消したうえで、停止ではなく一時停止（`animation-play-state:paused`）にしています。

**`.stream__rail` は `pointer-events:none` です。**
レールが帯の全面を覆うため、クリックを通してカードだけで受けています。

**コリドーは装飾扱いです。**
`.stream` に `aria-hidden`、各カードに `tabIndex = -1` を設定しています。
同じ行き先は下のカードセクションから辿れるので、キーボード操作はそちらが担当します。

**JavaScript が無効だとコリドーは空になります。**
レールを JavaScript で組み立てているためです。
